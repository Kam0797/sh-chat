### About Sh_chat

Sh_chat is a messaging app built with MERN stack and webSockets.

##### Major dependencies

- React [Frontend]

- Express.js/Node [Backend]

- MongoDB [DB]

- Socket.io

- Dexie.js [IndexedDB wrapper that makes life easier]

- Lucide icons [saved few hours]
